# 🏦 Bank Management System

A web-based Bank Management System developed as a university second-year, second-semester project. The application provides banking functionalities that allow users to manage accounts, perform transactions, pay bills, and manage payees through a user-friendly interface.

## 🚀 Features

- **User Authentication** – User registration and login functionality.
- **Account Management** – Create, view, update, and manage bank accounts.
- **Fund Transfers** – Transfer funds between accounts.
- **Bill Payments** – Manage and process bill payments.
- **Payee Management** – Add, edit, and delete payees.
- **Admin Dashboard** – Administrative management functionalities.
- **Advertisement Management** – Create, edit, and manage advertisements.
- **Comment Management** – Add, edit, and delete comments.

## 🛠️ Technologies Used

- Java
- Java Servlets
- JavaServer Pages (JSP)
- HTML
- CSS
- JavaScript
- MySQL
- Apache Maven

## ⚙️ Getting Started

### Prerequisites

Make sure you have installed:

- Java Development Kit (JDK)
- Apache Maven
- MySQL Server
- Apache Tomcat

### Installation

1. Clone the repository:

```bash
git clone https://github.com/dewmigithubdewmi/Bank_System.git
```

2. Navigate to the project directory:

```bash
cd Bank_System
```

3. Configure your MySQL database connection using the appropriate database configuration.

4. Update the database credentials in the project configuration.

5. Build the project using Maven:

```bash
mvn clean package
```

6. Deploy the generated WAR file to Apache Tomcat and run the application.
